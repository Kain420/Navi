# Navi — Telegram-бот для навигации по каналу

Telegram-бот, который индексирует посты одного канала и даёт навигацию по ним:
просмотр по фиксированным категориям, полнотекстовый поиск и постраничный доступ
к архиву через интерфейс из inline-кнопок.

## О проекте

Бот сделан под один конкретный канал — категории и приветствие адаптированы под
его тематику; это не универсальный шаблон.

## Возможности

- Просмотр постов по фиксированным категориям, которые определяются по хештегам
  и ключевым словам в тексте поста (набор категорий зашит под целевой канал).
- Полнотекстовый поиск по подстроке в архиве постов.
- Постраничный вывод постов через inline-кнопки (по 5 постов на страницу).
- Детальный просмотр поста со ссылкой на исходное сообщение в Telegram.
- Информация о канале (название, число подписчиков, постов в индексе).
- Ручное и периодическое обновление индекса постов.

## Архитектура

Один процесс выполняет всё в едином asyncio event loop: HTTP-сервер, Telegram-бот
и фоновую задачу обновления. Работает в webhook-режиме.

- **HTTP-сервер (`aiohttp`)** — обслуживает `POST /webhook` для апдейтов Telegram
  и `GET /` как health-check.
- **`python-telegram-bot` (v20)** — обработка команд и callback-запросов.
- **Telethon** — асинхронное получение истории и метаданных канала через
  пользовательскую сессию (`StringSession`).
- **Фоновая задача (`asyncio`)** — периодическое переиндексирование постов раз в
  30 минут.
- **In-memory индекс** — посты хранятся в списке на уровне модуля; базы данных
  нет, поэтому индекс перестраивается при каждом старте.

На бесплатном хостинге экземпляр засыпает при простое и холодно стартует примерно
за 30 секунд на следующем запросе.

## Конфигурация

Задаётся через переменные окружения (обязательные, если не указано иное):

| Переменная | Назначение |
|---|---|
| `API_ID`, `API_HASH` | Учётные данные Telegram API (Telethon) |
| `SESSION_STRING` | Строка пользовательской сессии Telethon |
| `SOURCE_CHANNEL` | Целевой канал (id или username) |
| `TOKEN` | Токен Telegram Bot API |
| `RENDER_EXTERNAL_HOSTNAME` | Публичный хост; используется для регистрации вебхука |
| `PORT` | HTTP-порт (по умолчанию `8080`) |
| `FETCH_LIMIT` | Максимум постов за одно обновление (по умолчанию `500`) |

## Стек

- Python 3.11
- python-telegram-bot 20.7
- Telethon 1.28.5
- aiohttp 3.9.1
- Развёртывание: Render (webhook-режим)

## Запуск

```bash
pip install -r requirements.txt
python worker.py
```

`Procfile` объявляет один процесс: `web: python worker.py`. При старте бот
регистрирует вебхук по адресу `https://<RENDER_EXTERNAL_HOSTNAME>/webhook` и
загружает начальную партию постов.
