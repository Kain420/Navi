# Navi — Telegram Navigation Bot

**Navi** — Telegram-бот для навигации по контенту канала:
категоризация постов, поиск по тексту и удобный доступ к архиву через inline-интерфейс.

Бот ориентирован на реальное использование и развёрнут в облачной среде.

---

## 📌 Возможности

- 📂 Категоризация постов по темам (на основе ключевых слов и хештегов)
- 🔍 Полнотекстовый поиск по архиву канала
- 📄 Пагинация постов через inline-кнопки
- 🔄 Фоновое обновление базы постов
- 📢 Просмотр информации о канале
- ⚡ Быстрый отклик за счёт кеширования данных

---

## 🧱 Архитектура

Бот реализован в webhook-режиме и адаптирован под ограничения облачного хостинга (задержка при старте ~30сек).

**Основные компоненты:**
- HTTP-сервер (`aiohttp`) — принимает webhook-запросы от Telegram
- `python-telegram-bot` — обработка пользовательских команд и callback-запросов
- `Telethon` — асинхронное получение истории и метаданных канала
- Фоновые задачи (`asyncio`) — периодическое обновление базы постов
- In-memory кеш — хранение постов для быстрого доступа

Архитектура построена вокруг одного event loop без блокирующих операций.
